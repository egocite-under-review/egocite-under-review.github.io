# EgoCITE Project Page

Anonymous project page for **EgoCITE: Context-Augmented Indexing and Time-Aware
Retrieval for Long-Horizon Egocentric Memory** (paper under double-blind review).

The site is plain HTML/CSS/JavaScript and deploys directly from `main` with
GitHub Pages. Its publication-first structure follows the
[Nerfies academic project-page template](https://github.com/nerfies/nerfies.github.io).

Results figures are responsive Chart.js visualizations backed by the exact
values from the paper's plotting scripts, with the original PNGs retained as
no-JavaScript and print fallbacks.
